# Lattice Monorepo

This repository hosts the next generation of the **Lattice** authorization engine.

- **packages/lattice-core** – framework-agnostic RBAC/ABAC engine with pluggable persistence.
- **examples/** – adapters and demo API wiring the core engine to various backends.

The legacy implementation has been removed to keep the new engine isolated. See [packages/lattice-core/README.md](packages/lattice-core/README.md) for usage instructions.
